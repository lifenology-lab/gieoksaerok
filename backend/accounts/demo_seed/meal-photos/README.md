# 데모 식사 사진

`seed_demo_persona` 명령이 사용하는 데모 식사 기록용 사진 폴더입니다.

## 파일

- `yukhoe-bibimbap.jpg` — 육회비빔밥 점심 사진. 음성 질의("오늘 점심 먹었던가?") 시
  조회되는 식사 기록에 함께 저장됩니다.

## 동작 방식

- `seed_demo_persona`를 실행하면 이 사진과 함께 **실행일 12:30 점심 식사 기록**이
  원본 데모 계정에 생성됩니다. (메뉴: 육회비빔밥, 미역국, 깍두기, 오렌지)
- 데모 체험을 시작하면 이 식사 기록이 체험 계정으로 복제됩니다.
- **촬영 당일에 `seed_demo_persona`를 실행**해야 "오늘 점심"으로 기록됩니다.
- 사진이 없어도 식사 기록 자체는 생성되며(음성 질의는 사진 없이도 동작),
  나중에 사진을 넣고 다시 실행하면 사진이 추가됩니다.

> 이 사진은 음식 사진으로 개인 식별 정보가 아니므로 영구 데모 데이터에 포함합니다.
> 인물(얼굴)·추억 사진 등 개인정보가 담긴 자료는 영구 데이터에 넣지 않습니다.
