# 개인 추억 사진 (personal)

부스/영상 데모에서 사용할 **실제 추억 사진**을 넣는 폴더입니다.

## 중요 — git에 올리지 않음
- 이 폴더의 **이미지 파일은 `.gitignore` 처리**되어 git에 커밋되지 않습니다.
  (개인 사진이라 공개 저장소에 노출하지 않기 위함)
- 폴더 구조와 이 안내(`README.md`, `.gitkeep`)만 git에 유지됩니다.
- 따라서 **EC2 등 배포 환경에는 이 사진들을 수동으로 업로드**해야 시드가 동작합니다.
  (예: `scp`로 이 폴더에 사진 복사 후 `seed_demo_persona` 실행)

## 파일 규칙
- 파일명: `YYYY_MM.jpg` (예: `2007_02.jpg`) — 시간순 정렬·서사를 위해 촬영 시기를 담습니다.
- 비율: 4:3 권장 (기존 데모 사진과 동일 레이아웃)
- 형식: JPG 권장 (용량 작고 로딩 빠름)

## 사용 원칙
- **가족 등 제3자 얼굴이 나온 사진은 넣지 않습니다.** (행사 노출 방지)
- 본인 동의 범위의 사진, 또는 얼굴이 없는 소재(풍경·사물)만 사용합니다.

## 시드 연동
- 사진을 넣은 뒤 `memory-items.json`(또는 별도 설정)에서 이 폴더의 사진을 참조하도록
  연결하면, `seed_demo_persona` 실행 시 추억 앨범에 등록됩니다.
- (연결 방식은 시드 코드 수정 시 함께 정합니다.)
